# Que es un daemon como `nodemon`?
Un **daemon** (o demonio) es un **proceso informático que se ejecuta en segundo plano**, realizando tareas automáticas o proporcionando servicios al sistema sin interacción directa con el usuario.

*   **Funcionamiento:** Suelen iniciarse automáticamente al arrancar el sistema y operan de forma independiente, sin interfaz gráfica. En sistemas como **Linux** y **Unix** se denominan daemons, mientras que en **Windows** se conocen como **servicios**.
*   **Etimología:** El término proviene de la **mitología griega**, donde un *daimon* era un espíritu o ser intermedio entre dioses y humanos que actuaba como guía o asistente, no como una entidad maligna.
*   **Ejemplos comunes:** Incluyen procesos como `sshd` (para conexiones seguras), `cron` (tareas programadas) y servicios de red o impresión.
