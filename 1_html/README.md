# HTML

## [Etiquetas semanticas](https://www.w3schools.com/html/html5_semantic_elements.asp)
Los contenedores fundamentales que debe tener cualquier pagina web son los siguientes

**Las cajas principales son las etiquetas semanticas, las subcajas que derivan de estas son los `div`**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Pagina recetas</title>
</head>
<body>
    
    <!-- Encabezado: Parte superior de la pagina -->
    <header>

        <!-- Contenedor de navegacion: Tendra los links para navegar por la pagina -->
        <nav>

        </nav>
    
    </header>


    <!-- Contenido principal de la pagina -->
    <main>

        <!-- Seccion del contenido principal -->
         <section>
            
         </section>
    
    </main>


    <!-- Pie de pagina -->
    <footer>

    </footer>

</body>
</html>
```
